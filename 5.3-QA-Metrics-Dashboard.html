What is in release 5.3

Features included in this release.
Feature areaWhat is new
APS (Autodesk) viewingAPS Standalone viewer with configurable properties (config, camera, cutting planes, navigation, rendering callbacks) and examples; APS with Model Composition and Geo BIM side by side; Graphics Service APIs use the host token; APS tokens created from the Reference App; design for an optional GIS overlay.
GIS and federated viewingGeo BIM View3D: a Mapbox map with each building opening in its own side-by-side View3D pane.
Viewer2D drawing-sheet callback and property for host apps; improved Navigator select, deselect, zoom and highlight; 2D/3D toggle without reloading.
InternationalisationIafViewer interface and examples in 17 languages: English, Japanese, Korean, Chinese (Simplified), Hindi, Telugu, Tamil, Kannada, Marathi, Gujarati, Malayalam, Bengali, German, French, Spanish, Italian and Portuguese (Brazil).
CompatibilityRelease validated against 5.2 and 5.1 on qa2 with developer sign-off.

Data sources & caveats

Read this before reporting these numbers upward:
  • Defect counts require Karthik Ramu to be both reporter and assignee — bugs assigned to Karthik Ramu but reported by someone else are excluded from the defect count, though they still exist in the release.
  • "Worked tickets" for PLG uses the saved filter 26617 as the base with the team assignee list and statusCategory = Done; do not rebuild it from fixVersion plus assignee. Rows assigned to teammates are shown in grey, not hidden. PA uses status = Done AND type IN (Story, Sub-task, Task) on the PA fix version.
  • Test-case counts cover only Xray Tests linked to the worked tickets and tagged with the 5.3 fix versions. a test's Done status is as confirmed by the tester; formal pass/fail results come from Test Execution issues.
  • Fix version names differ by project: PLG "Platform V5.3", PA "Reference App V5.3". Re-check the exact names in Jira before pulling data.
  • Your tracker listed PLG-3114 with the title of PLG-3144 (UX-UI - 2D,3D,MapBox Widgets zoom in and out is not working); PLG-3144 (assignee Karthik Ramu, reporter Raja Rajendraprasath, Done) is used. PLG-3144 has no fix version in Jira, so it is added by hand and the PLG defect list includes it although Raja reported it.
  • PLG-2967 (assignee and reporter Atul Kulkarni, no 5.3 fix version) does not meet the assignee and reporter rule and is not counted.
  • All 23 test cases are shown as Done on the tester's confirmation that they were completed; the Xray Test issues in Jira still show To Do and need updating. Tests linked to other 5.3 tickets are not counted, and no PA tests are linked to the worked tickets.
  • All 30 Xray test cases (PLG, fix version Platform V5.3, assignee Karthik Ramu) are Done in Jira.
