Automation scope — Platform V5.3

1 · E2E — Navigation menu (complete menu)  3 days

New for this release: full end-to-end coverage of the navigation menu rather than ticket-by-ticket coverage only. Every menu entry is walked and asserted, so a silent regression like PLG-2984 fails a run instead of being found by hand.

  • 2D/3D flyout — Navigator, Model Elements, Workflow
  • Right icon rail — every toolbar button and its active state
  • Viewer settings panel — all switches and sliders
  • Bottom toolbar — Search, Filter, List, Settings, Undo, Chat
  • Admin menu — User Group, Manage Model, Rest Connectors
  • Walk / BIM Walk modes including keyboard navigation

2 · Feasible tickets — QA viewer framework  4 days

The 8 tickets marked Manual+Auto are automated in the existing QA viewer framework. The 4 IPA plugin tickets stay manual — the Revit and AutoCAD plugins are desktop software outside the framework's reach.

  • PLG-2833 — View2d callback and property
  • PLG-2901 — Navigator deselect/select, zoom, highlight
  • PLG-2984 — Keyboard Walk Mode
  • PLG-2942 — GeoBim View3d side by side and camera
  • PLG-2989 — GIS initial center, None to Outline
  • PLG-2941 — ArcGIS _addLine / _addMesh
  • PLG-2958 — Internationalisation
  • PLG-2846 — Navigator selection after React 18
